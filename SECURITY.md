# Security policy

## Supported versions

Wryling is in beta and has no numbered releases yet. Only the latest code on
the `main` branch is supported. Please check a problem against it before
reporting.

## Reporting a vulnerability

Please report security problems privately, not in a public issue:

1. Go to the repository's **Security** tab.
2. Choose **Report a vulnerability**
   ([direct link](https://github.com/BeansAsset/wryling-browser/security/advisories/new)).
3. Describe the problem, the steps to reproduce it, and what an attacker could
   do with it.

You'll get a reply as soon as possible. This is a personal project, so please
allow a few days. Once a fix is on `main`, the report can be made public, and
you'll be credited unless you'd rather not be.

## What belongs here

This policy covers Wryling's own changes: the sidebar, Spaces, Home, the command
bar, split view, Trails, the Extras settings and the Shields list setup.

Wryling is built on Brave and Chromium. If the problem is also present in an
unmodified Brave or Chrome, please report it to them as well, so it gets fixed
for everyone:

- Brave: https://hackerone.com/brave
- Chromium: https://bughunters.google.com/report
